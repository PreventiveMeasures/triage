# @preventive/triage

[![](https://img.shields.io/npm/v/@preventive/triage?style=flat-square)](https://npmjs.org/package/@preventive/triage)
[![](https://img.shields.io/npm/l/@preventive/triage?style=flat-square&color=blue)](#license)

Client & relay server for triaging automated reports.

```sh
npx -p @preventive/triage triage-server --mode e2e   # or managed, managed-e2e, e2e-managed
```

`triage-server --help` lists the environment each mode reads.
